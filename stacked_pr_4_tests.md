---

## 🔄 How Merging Stacked PRs Works in GitHub
When practicing stacked PRs:
1. **Review & Merge PR 1** into `main`.
2. GitHub can automatically retarget PR 2 to `main`, or you can edit the base branch of PR 2 to `main`.
3. Then merge PR 2, and repeat sequentially for PR 3 and PR 4!
